SADAREM security paper print

Moves a SADAREM disability certificate down the page so it prints below the printed header on security paper. You get a print-ready A4 PDF. Files are processed in this browser and never uploaded.

    100% = original size

    3 · Download and print

    Add a certificate PDF to begin.
    • Print on A4 at Actual size / 100%. Turn off “Fit to page” or the shift is undone.
    • Do one test print on plain paper and hold it against the security paper to check the position. Adjust and download again if needed.
    • Free tool. Independent, not affiliated with SADAREM or the Government of Andhra Pradesh.
    • The printed copy keeps the look of the signature box, but the file it makes cannot be verified digitally. Keep the original PDF for online submission and verification.
